# Deva · 对话优先的智能体工作台

> 把「和 AI 对话」本身做成一个完整的工作环境：聊着天就把活干了，不用切换到别的应用。

Deva 是一个桌面应用（Windows / macOS / Linux）。它不是「带个聊天框的编辑器」，而是**以对话为唯一主界面**的智能体工作台：打开就是一个对话，所有能力——读写文件、跑命令、查代码、连外部服务、定时自动执行——都从对话里发起。

- 下载即用，无需配置环境（安装包自带运行时）
- 中英双语界面，随系统主题（亮 / 暗）
- 所有数据明文可备份、可手改、可迁移

## 亮点

**💬 对话是一等公民**

- 打开应用即是对话；新建对话、搜索历史、多对话并行
- 一条对话一个文件，聊得再多也不拖累其他对话
- 对话轮次导航：右侧索引列出所有用户发言，长对话一键跳转
- 挂载一个文件夹，对话就聚焦其中；卸载即回到全机通用助手
- 支持附加图片、文档、代码文件，直接发给模型

**🧠 多模型 / 多服务商，随时切换**

- 兼容 OpenAI、Anthropic（以及各类兼容接口与本地模型）
- 每个对话可单独选模型，也可跟随全局默认
- 内置连通性测试与模型清单拉取，填不填得通一眼可见
- 密钥用系统级加密存储，明文永不离开主进程

**🎭 角色（Personas）**

- 为对话赋予不同的性格、语气与专长
- 内置开箱即用的默认角色；也可自己创建，或让 AI 在对话里一步步引导你拟一个
- 多角色可叠加启用，各自独立开关

**🧩 扩展能力**

- **技能（Skills）**：把常用流程封装成「/技能名」一键触发，也可让模型按场景自动命中
- **子智能体（Subagents）**：把费时的大范围检索 / 方案调研派发出去独立完成，结果直接回收到当前对话
- **MCP 服务**：接入任意 MCP（本地 stdio 子进程或远程 SSE / HTTP），其工具自动并入对话能力

**⏰ 定时任务 / 自动任务**

- 口语化下指令即可：「每天 10 点给我发今天的热点新闻」
- 任务在创建前先给你一张**可编辑的授权名片**——你能改时间、指令、角色、模型，确认后才真正建立
- 到点自动执行，全程**不再弹任何确认框**；关掉窗口、收到托盘里也照常触发
- 执行结果回到一个专属会话，并弹系统通知，点击即定位
- 出错自动暂停并告警，不会无限空转烧额度

**🛠 内置工具链**

- 文件读写与精确编辑、目录浏览、glob 文件名匹配、正则内容搜索、网页抓取
- 集成终端（多会话、常用 Shell 自动识别）
- Git 源代码管理：查看改动、暂存、提交、拉取、推送、切分支，复用系统已存的登录态，零凭据配置；还能用 AI 生成提交信息

**🔒 安全与隐私**

- 敏感操作先授权、后执行；危险动作有硬底线拦不住
- 文件访问限定在已打开的目录内，路径穿越自动封堵
- 密钥经操作系统加密体系（Windows DPAPI / macOS Keychain / Linux libsecret）落盘
- 单实例锁，定时任务不会被重复触发

**📦 便携**

- 所有数据集中在一个目录（默认 `~/.deva`），用 `DEVA_HOME` 环境变量整体迁移到任意盘
- 长对话自动压缩摘要，上下文始终保持在安全区，可以一直聊下去

## 快速开始

### 使用

从 [Releases](https://github.com/sqfcyily/deva/releases) 下载对应平台安装包，双击安装后启动即可。

首次打开后，在「设置 → 模型」里填入服务商地址与密钥，即可开始对话。

### 从源码运行

需要 Node.js ≥ 20 与 pnpm：

```bash
pnpm install
pnpm dev          # 启动开发预览
pnpm build        # 构建产物（类型检查 + 打包前端）
pnpm package:win  # 打包 Windows 安装包（package:mac / package:linux 同理）
```

## 数据都在哪

| 内容 | 位置 |
| --- | --- |
| 应用设置（主题 / 语言 / 模型 / 启用态） | `~/.deva/config.json` |
| API 密钥（加密） | `~/.deva/secrets.json` |
| 全部对话记录 | `~/.deva/data/chats/` |
| 定时任务 | `~/.deva/tasks.json` |
| MCP 服务配置 | `~/.deva/mcp.json` |
| 技能 | `~/.deva/skills/<技能名>/SKILL.md` |
| 角色 | `~/.deva/personas/<角色名>.md` |

以上均可用 `DEVA_HOME` 环境变量整体改到别的位置。配置与对话为可读 JSON，可备份、可版本化；只有密钥是加密的。

## 常见用法

- **「帮我把这个项目里的接口都列出来」** → 挂载文件夹后直接说，模型自己检索与阅读
- **「每天 9 点把昨天的提交整理成日报」** → 建一个定时任务，确认授权名片后到点自动执行
- **「调研一下这个库怎么用」** → 派一个子智能体去大范围检索，结论直接回到当前对话
- **「帮我提交一下改动」** → 在 Git 面板里暂存、让 AI 写提交信息、推送，凭据用系统已有的

## 开发约定

- 双绿验证：`pnpm typecheck && pnpm build`
- 不新增运行时依赖（Git 功能对系统 `git` 的依赖是唯一例外）
- 新增界面文案走 `i18n` 中英双份
